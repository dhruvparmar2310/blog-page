## Project Setup:

- First install all the required dependencies by running the below CLI:

```javascript
npm i
```

- Now start the local server by running the below CLI, you will be able to see your local server runs on `http://localhost:3050`:

```javascript
npm run dev
```

- You can add your Database Connection String in env:

```javascript
PORT=3050
DB_CONNECTION_URI=paste your DB connection string here
```
