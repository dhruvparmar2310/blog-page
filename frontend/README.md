### References of Article:

- [https://www.crictracker.com/](https://www.crictracker.com/)

## Project Setup:

- First install all the required dependencies by running the below CLI:

```javascript
npm i
```

- Now start the local server by running the below CLI, you will be able to see your local server runs on `http://localhost:3000`:

```javascript
npm run dev
```

### Extra Notes:

- I have made extra efforts for website **Header**, and you can see the task in **Blogs > Click the specific Blog**
- I have also used Backend api also few dummy data for **comments**, **tour guides**, etc.
- You can add your backend endpoint in env:

```javascript
NEXT_PUBLIC_API_ENDPOINT=paste your backend endpoint here
```
